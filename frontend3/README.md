# frontend3 (Vercel-ready)

This is a complete Next.js frontend for **iWas Findex**, prepared for Vercel deployment.

## Run locally

```bash
cd frontend3
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import the repo in Vercel.
3. Set the root directory to `frontend3`.
4. Add environment variable `NEXT_PUBLIC_API_BASE_URL` (optional).
5. Deploy.
