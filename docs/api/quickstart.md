# API quickstart

1. Run `npm install`.
2. Copy `.env.example` to `.env.local`.
3. Add `ALPHA_VANTAGE_API_KEY` when live provider data is required.
4. Run `npm run dev`.
5. Open `http://localhost:3000/api/market?symbol=AAPL`.

The endpoint works without a key by returning clearly labelled demo data.
